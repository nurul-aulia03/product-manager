# Product Manager System

Sistem manajemen inventaris barang berbasis web sederhana yang dibuat menggunakan PHP dan MySQL.

## Fitur Utama
- Menampilkan daftar produk (Read)
- Menambah data produk baru (Create)
- Mengubah data produk (Update)
- Menghapus data produk (Delete)

## Teknologi
- PHP
- MySQL
- CSS
